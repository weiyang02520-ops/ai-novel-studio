# M6 Reviewer Implementation Plan

> **For implementer:** Use TDD throughout. Write each failing test first, run it and observe the expected failure, then add only the minimal production code required.

**Goal:** Add a fail-closed, revision-bound Reviewer gate that moves an AI draft to READY only after a valid PASS report while never modifying prose or invoking Writer.

**Architecture (implemented):** Architecture B keeps REVIEWING process-local while canonical draft bytes remain unchanged during the Provider call; no pending sidecar is persisted and recover returns `NO_PENDING_REVIEW`. Provider-independent schema/runner/context code feeds a short-lock, exact-revision ReviewService transaction that owns report/status/history persistence.

**Tech Stack:** Python 3.11 stdlib, existing BaseProvider/ProjectStore/History/ContextBudget abstractions, pytest, localhost OpenAI-compatible mock server.
